## Текущий статус проекта (2026-10-20, поздний вечер)
1. **Критический баг найден по фото экрана телефона:**
   - На экране отображалось:
     `FB addr=00000000 stride=00000000`
     `DISP w=00000000 h=00000000`
     `FMT bpp=00000000 bswap=00000000`
   - Clang при флаге `-fpie` генерировал таблицу GOT (`.got`) со статическими адресами от 0 (`0x4518`, `0x8f0`).
   - Поскольку шим работает bare-metal без динамического линковщика (`ld.so`), разыменование переменных через GOT читало нули из физической памяти `0x00004518`.
   - В результате:
     - `dsi_flush_loop` передавался в PSCI как `0x8f0` вместо реального `0x400808f0` (CPU 1 мгновенно падал).
     - `ba->Video` в XNU передавался с `v_baseAddr = 0` и `v_rowBytes = 0` (XNU мгновенно падал при обращении к экрану).
2. **Исправление:**
   - В `shim/build.sh` флаги компиляции изменены на `PIC_FLAG="-fno-pic"` и добавлен `-fno-jump-tables`.
   - Таблица GOT полностью устранена. Теперь все переменные и функции (`con_fb`, `con_stride`, `dsi_flush_loop`) резолвятся через прямые инструкции `adr`/`adrp` (PC-relative).
   - CPU 1 стартует по правильному адресу `0x400808f0` и циклически пинает дисплей.
   - XNU получает правильные адреса `v_baseAddr = 0x7E020000`.
3. **Готовые бинарники собраны и подписаны:**

   - Команда прошивки: `fastboot flash boot shim/out/shim-boot.img`.
